# KNN原理

算法思想、距离度量（欧氏/曼哈顿/闵可夫斯基）、k值选择、维度灾难

## 2.1 核心思想 ：物以类聚

KNN（K-Nearest Neighbors, K近邻)是最朴素也最优雅的分类器--*它根本不”学习“*

训练阶段只是把数据存起来， 预测时现场计算

**算法步骤**(以C语言视角看)：

```c
int knn_predict(struct Sample train[], int n, struct Sample x, int k) {
    // 1. 计算x与所有n个训练样本的距离   ->O(n*d)
    // 2. 找出距离最小的k个样本         -> 排序或选择算法
    // 3. 这k个邻居的label投票         -> 多数票获胜
}
```

KNN 的核心超参数基本只有 $k$ 一个 ---- 这就是它被称为”懒惰学习“（lazy learning）的原因: 训练0成本， 预测O(n*d)

> **超参数(hyperparameter)**就是由人指定，而不是算法自己学出来的参数。

> **模型参数**是训练后算法学出来的

2.2 距离度量 -- "近"怎么定义

度量| 公式 | 直觉
-|-|-
欧氏距离（L2） | $\sqrt{\sum_i^n {(x_i - y_i)^2} }$ | 直线距离， 最常用
曼哈顿距离（L1） | $\sum_i^n{\|x_i - y_i\|}$ | 只能横竖走，像纽约街道
闵可夫斯基| $\left(\sum_{i}^{n}{\|x_i-y_i\|^p}\right)^\frac 1  p$ | L1和L2的统一形式, p>=1为参数， p不同，对应不同距离计算方式

**为什么需要闵可夫斯基距离**

它提供了一个可调参数$p$:

- 小$p$: 关注总体差异
- 大$p$: 更关注某一维度上的大偏差
- $p \to \infty$: 只看最大偏差

**机器学习中的经验**

- 特征维度较多且稀疏（文本特征）时，常用 曼哈顿距离（p=1）；
- 连续数值特征较多时，常用 欧几里得距离（p=2）；
- 若希望对某个维度上的大误差更敏感，可以选择 p>2；
- 使用闵可夫斯基距离前通常需要先做特征归一化（Normalization），否则量纲大的特征会主导距离计算。

> C实现提示： 算欧氏距离时用$sqrt$放在最后， 中间用平方和比较大小完全够用--反正$sqrt$是单调函数， 比大小结果不变。省掉开方，速度快，精度不丢
>

> **特征缩放问题**： 如果特征1范围是[0,1], 特征2范围是[0,10000], 距离会被特征2完全支配。解法：归一化 (Min-Max) 或 *标准化 (Z-score)*，实战中必做的一步

## 2.3 k值怎么选 -- 偏差方差在这里具象化

k 太小（如 k=1）→ 过拟合：对噪声点极度敏感，决策边界锯齿状
k 太大（如 k=100）→ 欠拟合：邻居跨类别太多，边界过于平滑

经验做法：$k = \sqrt n$（n 为样本数），然后交叉验证微调

奇数原则：二分类时 k 取奇数避免平票。

## 2.4 维度灾难 -- KNN的死穴

特征维度升高时，数据在高维空间变得稀疏，"近邻"都不再近。有个著名的直觉结论：

> 在 d 维空间，要捕捉p(eg:10%)的数据点，边长需要是 ${p}^{\frac 1 d}$——维度越高，需要的范围越接近全覆盖。

> 比如：
> $L=0.1^{1/100}=0.977$

> 上述是由 $p = L^d$推导出

缓解手段： 降维（PCA）， 特征选择，换用基于距离假设更稳的模型
