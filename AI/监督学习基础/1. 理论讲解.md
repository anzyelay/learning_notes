# 理论讲解

监督学习框架：数据集划分、评估指标（准确率/精确率/召回率）、偏差-方差权衡

## 1.1 什么是监督学习

监督学习 = 从 (特征, 标签) 对中学习映射 $f: X → y$

用你最熟悉的 C 语言类比来理解：

```c
// 一条训练数据 = 一个结构体
struct Sample {
    double features[4];   // 特征 X：如花瓣长、花瓣宽
    int label;            // 标签 y：如 0=山鸢尾 1=变色鸢尾
};
```

训练就是给模型一堆这样的结构体，让它学出一个函数$f$，新来一个未知样本时，能算出它的`label`。

两类核心问题：

类型 | 输出
-|-
分类 (Classification)	| 离散类别
回归 (Regression)	| 连续数值

本周的 `KNN` 和决策树都是分类器。

---

## 1.2 数据集划分 — 最关键的纪律

**训练集 (train, ~70%)  →  模型在这里学**

**验证集 (valid, ~15%)  →  调参时用（选k、选树深度）**

**测试集 (test,  ~15%)  →  只在最后用一次，模拟"考试"**

> ⚠️ 铁律：测试集是"考卷"，训练过程中绝对不看。你 C 程序员应该能理解：测试集就是 final exam，不能一边做题一边翻答案。

- **留出法 (Hold-out)**：一次划分，简单但有随机性。

- **交叉验证 (K-fold)**：把数据切成 k 份，轮流取一份当测试，其余训练，最后取平均。sklearn 里一行代码实现，之后我们会用来验证你的 C 实现。

## 1.3 评估指标 — 分类器的"考分"

以二分类为例，先建立混淆矩阵（Confusion Matrix）：

预测正例 |预测负例
-|-
实际正例   |    TP(正确正) | FN(漏报)
实际负例   |    FP(误报)  |  TN(正确负)

指标| 公式 | 直觉
-|-|-
准确率 Accuracy	| (TP+TN)/总数 | 答对的比例（类别不平衡时骗人）
精确率 Precision |	TP/(TP+FP) | 预测为正的里面，有多少真对
召回率 Recall	| TP/(TP+FN) | 真正的正例里，抓住了多少
F1 分数 |	2·P·R/(P+R) | 两者的调和平均

**记忆口诀:** 精确率看"查得准不准"，召回率看"找得全不全"。

> 💡 举例：癌症筛查场景，FP 只是虚惊一场，FN 会致命 → 优先高召回率。

## 1.4 偏差 vs 方差 — 模型的"性格"

- 高偏差 (Bias)     = 欠拟合 (Underfitting)  → 太笨，训练集都学不会

- 高方差 (Variance) = 过拟合 (Overfitting)   → 太聪明，把训练集背下来了

C 程序员直觉：过拟合就像把 if-else 分支写满了每个训练样本的硬编码值 — 训练集上100%正确，新数据一进来就崩。

判断方法：

- 训练集误差高 + 测试集误差高 → 欠拟合 → 加复杂度

- 训练集误差低 + 测试集误差高 → 过拟合 → 减复杂度/正则化/加数据
