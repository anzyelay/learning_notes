# 决策树原理

什么是决策树?

一句话：

**决策树通过不断提问，把数据一步步分开**

决策树最大优点：

**可解释性极强**

训练过程如下：

```txt
遍历所有特征
    ↓
遍历所有候选阈值(邻近中值)
    ↓
计算Gini
    ↓
选择最佳分裂
    ↓
递归生成左右子树
    ↓
利用 max_depth
       min_samples_split
       min_samples_leaf
防止过拟合
```

> 决策树 = 递归 if-else → 选"分割条件"靠不纯度指标（类别熵 Gain / 基尼）→ 树建完用剪枝防过拟合 → CART(基尼) 是最适合手写的版本。

**决策树最喜欢的是切分后左右两侧类别越纯越好**

因此决策树最核心问题变为: "哪种切法最纯", 训练过程就是在找这些最佳切分点

不纯度指标有如下两种计算方式：

- 信息熵
- 基尼不纯度

## 信息熵

$$H(D) = -\sum_{i=1}^{c} p_i \log_2 p_i$$

其中 $p_i$ 是类别 $i$ 在数据集中的占比。

**信息增益** Information Gain（划分前后熵的下降量）：

其核心思想即：

```txt
信息增益 = 切分前的混乱 - 切分后的混乱
```

$$Gain = H(D) - \sum_{v} \frac{|D_v|}{|D|} H(D_v)$$

$H(D)$: 划分前整个数据集的熵

$\sum_{v} \frac{|D_v|}{|D|} H(D_v)$: 划分后各子集熵的加权平均（条件熵）

**ID3**: 每次选择信息增益最大的特征作为当前节点

> 缺陷： 偏爱取值数量很多的特征, 例如，如果用一个“身份证号”作为特征，每个样本的取值都不同，划分后每个子集的熵都为0，信息增益达到最大，但这棵树完全没有泛化能力。

**C4.5**: 由于ID3的缺陷，提出了改进版

> 思想很简单： ID3看**信息增益**，C4.5看**信息增益率**

## 基尼不纯度

 基尼不纯度 Gini Impurity —— CART(Classification and Regression Trees) 用（本周我们用这个）

 它的物理意义： **从一个数据集中随机抽取两个样本，这两个样本属于不同类别的概率**

**单节点的基尼指数公式：**

假设数据集$D$中有$K$个类别，第$k$类样本比例为$p_k$，则：

 $$Gini(D) = 1 - \sum_{k=1}^{K} p_k^2$$

- $p_k^2$ 表示连续抽到两个第$k$类样本的概率。
- $\sum p_k^2$ 表示连续抽到两个**相同类别**样本的总概率。
- 用1减去它，剩下的就是抽到两个**不同类别**样本的概率。

直觉：随机抽两个样本，它俩类别不同的概率。越小越好。

- 全同类：$1-1^2=0$
- 两类各半：$1-(0.5^2+0.5^2)=0.5$

`CART` 选择使分裂后 Gini 加权和最小的特征：

$$Gain_{gini} = G(D) - \sum_{v}\frac{|D_v|}{|D|}\,G(D_v)$$

## 为何使用gini而不用entropy?

1. 计算效率（最直接的工程原因）
2. 对“不纯度”的惩罚力度不同（数学性质）

    虽然两者都是衡量数据混乱程度的指标，且形状非常相似，但它们对概率分布的敏感度不同：

    - 基尼指数：对概率分布的极端值更敏感。当数据集中存在一个占据绝对多数的类别时，基尼指数下降得更快。它更倾向于将多数类单独分出来，使节点迅速达到“纯”的状态。

    - 信息熵：对概率分布的变化相对更平滑。它更倾向于产生更平衡的分裂（即让左右子树的样本比例尽量接近 50:50）。

    在工程实践中，基尼指数这种“快速提纯”的特性往往能带来更好的分类效果，并且生成的树通常深度更浅

3. 与回归任务的统一性（算法设计的优雅）

    CART 的全称是“分类与回归树”，它的设计初衷是建立一个统一的框架。

    - 在回归树中，CART 使用的是均方误差（MSE），其本质也是基于平方运算$(y-\hat y)^2$。

    - 在分类树中使用基尼指数$(1-\sum p_k^2)$，使得分类和回归在底层数学逻辑上保持了高度的一致性（都是围绕平方展开）。

    - 如果在分类时用熵，在回归时用 MSE，算法的内部逻辑就会显得割裂。
